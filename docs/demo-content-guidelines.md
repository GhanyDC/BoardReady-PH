# Demo Content Guidelines

Use these rules when adding sample content for local testing, demos, or private beta preparation.

## Allowed

- Use only original, self-made demo questions.
- Label demo questions clearly as sample or demo content.
- Keep demo content minimal and for testing only.
- Use generic exam-prep wording that can fit future exam tracks.
- Review all real content before publishing it to reviewers.
- Log external drills only as score metadata: title, subject, topic, score, total items, mistakes, weak topics, notes, and date taken.

## Not Allowed

- Do not copy review-center hardcopy drills.
- Do not paste copyrighted reviewer materials.
- Do not store copied review-center questions.
- Do not upload scans, photos, PDFs, files, or attachments.
- Do not add OCR, scanning, photo capture, or hosted-material workflows.
- Do not imply that BoardReady PH guarantees exam passing.

## Demo Question Standard

- Question text should be short, original, and clearly artificial if used only for testing.
- Choices A-D must be complete.
- Exactly one answer must be correct.
- Rationale must explain why the correct answer is defensible.
- Source type should be `self_made` or another appropriate non-copyrighted category.
- Status should remain `draft` unless an admin intentionally publishes it for testing.

## Seed Content

This project does not currently require a demo seed file. Documentation-only demo guidance is enough for Sprint 11. If a seed file is added later, keep it minimal, original, clearly labeled, and safe to delete.
